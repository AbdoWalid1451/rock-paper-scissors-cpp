# Rock Paper Scissors Game (C++)

Console-based Rock Paper Scissors game built using C++.

## Features

- Play against the computer

- Random computer choices

- Multiple rounds support

- Colored console output for winners

- Final game statistics

- Replay option

## Technologies

- C++

- Standard Library

- Console Application

- Functional Programming

## Game Rules

- Paper beats Stone

- Stone beats Scissors

- Scissors beats Paper

## How to Run

### Using Visual Studio

1. Open the project

2. Build the solution

3. Run the program

### Using g++

g++ main.cpp -o game

./game
